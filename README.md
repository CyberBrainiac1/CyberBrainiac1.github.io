# Pranav Emmadi — Portfolio

A responsive personal portfolio for Pranav Emmadi, a high-school robotics builder working across mechanical design, mechatronics, embedded systems, controls, and physical AI.

## Pages

- **Home** — introduction, current CATCH research, selected projects, and recognition
- **Projects** — interactive index of 20 robotics, software, and hardware projects
- **About** — education, FIRST experience, engineering process, skills, awards, and interests

## Design

The interface uses a minimalist blueprint direction with a 28 px drafting grid, technical figure labels, IBM Plex Mono, Space Grotesk, schematic project plates, responsive layouts, and persistent light/dark themes.

## Run locally

This is a dependency-free static website. Open `index.html` directly or serve the folder locally:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:4173/`.
